# Dreams of a Nobody

Welcome to **Dreams of a Nobody**, an open repository for ideas, tools, and prototypes designed to make the engineering and making process easier and more accessible.

## CAD & Prototyping Assistant

This repository currently hosts the **CAD Assistant**, a command-line interface (CLI) tool built to help makers, engineers, and hobbyists with 3D printing and design.

### Features

-   **Material Guide**: Detailed properties, printing temperatures, and pros/cons for common 3D printing materials (PLA, ABS, PETG, TPU, etc.).
-   **Design Tips**: Engineering guidelines for wall thickness, tolerances, overhangs, and bridges to ensure your parts print correctly and fit together.
-   **Prototype Logger**: A built-in system to quickly log, save, and manage your "spitball" prototype ideas so you never lose a spark of inspiration.

### Getting Started

#### Prerequisites

-   Python 3.x installed on your system.

#### Installation

1.  Clone this repository:
    ```bash
    git clone https://github.com/your-username/dreams-of-a-nobody.git
    cd dreams-of-a-nobody
    ```

2.  (Optional) Create a virtual environment:
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

#### Usage

Run the assistant using the following command from the root directory:

```bash
python3 cad_assistant/main.py
```

Follow the on-screen menu to navigate through materials, tips, and the idea logger.
